# ImpactoLocal

Plataforma aberta e _serverless_ de triagem socioeconômica e gestão de filas de espera para cursinhos populares, mutirões de saúde e projetos sociais no Brasil.

Construído com Svelte 5, Supabase e Cloudflare Pages, o projeto adota a arquitetura _Bring Your Own Backend_ (Traga seu Próprio Servidor). Isso garante custo zero de infraestrutura para quem desenvolve e para a organização social, operando de forma rápida mesmo em celulares antigos e conexões 3G instáveis.
