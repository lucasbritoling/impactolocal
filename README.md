# 🚀 ImpactoLocal

Plataforma aberta e *serverless* de triagem socioeconômica e gestão de filas de espera para cursinhos populares, mutirões de saúde e projetos sociais periféricos no Brasil.

Construído com Svelte 5, Supabase e Cloudflare Pages, o projeto adota a arquitetura *Bring Your Own Backend* (Traga seu Próprio Servidor). Isso garante **custo zero de infraestrutura** para quem desenvolve e para a organização social, operando de forma instantânea mesmo em celulares antigos e conexões 3G instáveis.
